테스트 안내

이미지 시간은 실제 기기에서 이미지가 표시되기까지 걸린 시간이며 브라우저 캐시와 스크롤 위치에 따라 다릅니다. Apple은 약 분당 20회 이내의 API 호출을 권고합니다. 일반 fetch가 CORS로 실패하면 사이트의 인증정보에 접근할 수 없는 샌드박스 iframe 안에서 공식 JSONP 방식을 시도합니다. 두 방식 모두 실패하면 오류를 그대로 표시합니다. Apple 앨범아트의 정식 서비스 이용 조건은 별도로 검토해야 합니다.
